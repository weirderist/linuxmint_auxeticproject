Simulate (relaxation and yarn length migration)
Select a result.

The solver runs only when Simulate is pressed. Contact stiffness is a numerical choice (tested on one fabric); the yarn is treated as a solid elastic rod, so its bending stiffness is an upper estimate for a twisted staple yarn.

Tile analysis (periodic yarn tile: natural curvature and Poisson's ratio)
Select a result.

 
One tile = one repeat of the result's stitch matrix. Run only one job at a time. Rest-shape reset follows Sperl et al. (2022) Sec. 7.2; the initial rest curvature scale and reset fraction are modelling choices, not sourced. Large matrices are refused (vertex limit).
