# Slip extensions, diagnostics and the tightness record

**Status 2026-11-20: implemented and tested without the solver; never run in the solver; not committed.** Code: `scripts/slip_ext.py`, `scripts/round_diag.py`, hooks in `scripts/relax_state.py` (`migrate`, `run`) and options in `scripts/relax_job.py`. Tests: `tests/test_slip_ext.py`. Everything is opt-in and off by default; with all options off the numbers are bit-identical to before (tested). Every constant is UNSOURCED.

## What was built (K's reduced list)
1. **`--diagnostics`**: `diagnostics.csv` per run, one row per outer round (30 columns, defined in `round_diag.py`): loop rest length and geometric length (mean/min/max for all / outer / inner loops, each against the start of the run), the share of the length change stored in the rest length, number and size of slips, a fold descriptor, the drive strength of the round. Regions are defined on the boundary term of the sectioned field (outer = G_b >= 0.75, inner <= 0.25; UNSOURCED thresholds).
2. **`--slip-friction-load mu_n`**: the slip limit becomes `T_hi <= max(T_lo,0) exp(mu phi) + mu_n F_n`, `F_n = k_contact x overlap` of the contact.
3. **`--slip-drive e` and `--slip-drive-decay N`**: a persistent effective tension offset `+-0.5 e EA (G_b - G_a)` at every contact node, from the sectioned loop field (targets and minimum strength from `--loop-grade-target` / `--loop-grade-min-strength`; no `--loop-grade` needed). `e` is signed (-0.1 to 0.1); the decay is exponential in outer rounds (0 = none, the default; K's choices).
4. **Tightness factor** `sqrt(tex) / loop length` (tex = 590.5 / Ne, loop length = mean as-built yarn length per loop) recorded in `meta.json` under `simulations[-1].tightness` for every run; used nowhere. Not added, as agreed: the exponents p and q, the recovery outputs, any change of defaults.

## Findings while building (all from arithmetic on saved states, no solver)
- **A drive that jumps at loop boundaries acts almost nowhere.** The slip rule acts only at contact nodes and loop boundaries are rarely contact nodes (the first version changed 568 to 576 slips on the saved state of fidelity run 0001). The drive therefore uses the loop values interpolated along the yarn between loop centres, times the mean segments per loop (`loop_grade.drive_field`), so every node has a small step and `e` means the strain imbalance per unit G difference between adjacent loops. The starting grade keeps its own piecewise field (unchanged, tested bit for bit).
- **The drive has to beat the friction limit.** At the as-built start the campaign's pre-strain (+5.4 %) puts 4.3 N on the lower-tension side, so `exp(mu phi) T_lo` exceeds a drive offset of `e = 0.01` (0 transfers); `e = 0.1` exceeds it (657 transfers on a single jersey). It acts where the strain has relaxed (strain-free start: 1004 transfers at `e = 0.01`). The drive only starts once the first relaxation has removed the pre-strain.
- **Scale of the constants on the saved relaxed state of run 0001** (one pass, baseline 568 slips, 3.7e-2 mm in total, largest 6.6e-4 mm, cap 2.5e-2 mm): `e` 0.0005 / 0.001 / 0.003 / 0.01 / 0.03 / 0.1 gave 1.1x / 1.4x / 4.1x / 22x / 80x / 277x the baseline total, the largest transfer reaching 3 % to 52 % of the cap. The median normal force `F_n` is 0.22 N (overlap 1.2e-5 mm) against tensions of 0.1 to 0.6 N, so `mu_n` 0.001 to 0.03 changes almost nothing, 0.3 leaves 81 % of the slips and 1 leaves 62 %. Useful exploratory ranges: `e` 0.001 to 0.01, `mu_n` 0.1 to 1. These are arithmetic on one old unsettled state, not calibrated values.
- **Decay and recovery.** With positions held fixed, a decaying drive lets the stored elastic strain push rest length back, so the net movement toward higher G ends smaller than with a constant drive (3.8e-2 against 6.2e-2 in the test). In a real run the relaxation re-equilibrates the positions between rounds, so the real effect can differ.

## UNSOURCED constants (new)
`mu_n`; `e` (and its range -0.1 to 0.1); the decay `N`; the additive form of the friction term; the effective-tension-offset form of the drive with its split +-0.5; the exponential decay; the use of the sectioned loop-grade field as the drive potential (smooth interpolation, segments-per-loop scaling); the region thresholds 0.75 and 0.25; the definition of `share_l0`. The tightness factor itself is a standard definition; the loop length used is the as-built value of the build, not a measurement.
